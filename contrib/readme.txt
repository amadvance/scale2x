This directory contains some user contributions for Scale2x.

Please note that they are not part of the official Scale2x
project and are unsupported.

sdl/
	SDL C implementation by Pete Shinners (Public Domain)

java/
	Java implementation by Randy Power (GPL)

java2/
	Another Java implementation from:

	http://www.cokeandcode.com/scale2x/

visualc/
	VisualC MMX assembler implementation by VisualBoy from
	the VisualBoyAdvance emulator (GPL)

freebasic/
	FreeBasic implementation by Richard Eric M. Lope from:

	http://dhost.hopto.org/aapproj/fbgfx/demos/scale2x.zip

ogl2/
	OGL2 shaders from:

	http://www.pbernert.com/pete_ogl2_shader_scale2x.zip

	and:

	http://www.foren.de/system/thread-scale2xrev3glslshader-pete_bernert-266904-947832.html

ps/
	Pixel shader from:

	http://home.amis.net/lkslavi/dosbox.html

perl/
	PERL implementation from:

	http://search.cpan.org/~bricas/GD-Image-Scale2x-0.02/

mactech/
	MacTech article decribing EPX

pixel/
	Depixelizing Pixel Art
